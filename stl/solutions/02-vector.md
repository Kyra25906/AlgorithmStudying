# 第二课参考答案

先完成讲义练习，再阅读答案。

## 1 拷贝独立

a 仍是 [1,2]。`vector<int> b=a;` 是拷贝构造，复制了元素的值，b 与 a 是两份独立数据；改 b[0] 只影响 b。

## 2 返回值与位置

`a.erase(a.begin())` 删除首元素 1，返回指向原第二个元素 2 的迭代器，结果为 [2,3]。`insert(a.end(), 2, 5)` 在末尾追加两个 5，得到 [2,3,5,5]；n=0 时返回 pos（即 end()）。

## 3 漏删分析

删除后元素左移，随即 i++，会跳过紧跟在被删元素之后的那个元素；连续命中还会越过 size 造成越界。例如 [3,1,2,3] 删 3：i=0 删掉 3 后变为 [1,2,3]，i=1 看的是 2，跳过了 1。正确做法见第 7 节三种写法。

## 4 删除负数

读入后任选一种安全写法，例如筛选：

```cpp
std::vector<int> kept;
kept.reserve(a.size());
for (int v : a) if (v >= 0) kept.push_back(v);
a.swap(kept);
```

或从后往前删：

```cpp
for (int i = (int)a.size() - 1; i >= 0; --i)
    if (a[i] < 0) a.erase(a.begin() + i);
```

测试：空→空；[-1,-2]→空；[1,2]→[1,2]；[-1,2,3]→[2,3]；[1,-2,-3]→[1]。筛选法时间 O(n)、空间 O(n)；从后往前删最坏 O(n²)。

## 5 删除第一列

读入 r、c 与矩阵 m，构造新矩阵删第一列：

```cpp
std::vector<std::vector<int>> out(r);
for (int i = 0; i < r; ++i)
    for (int j = 1; j < c; ++j)
        out[i].push_back(m[i][j]);
```

测试：单列 [ [1],[2] ]→[ [],[] ]（r 行 0 列）；单行 [ [1,2,3] ]→[ [2,3] ]；1×1 [ [5] ]→[ [] ]。c=1 时注意别访问 m[i][1]。

## 6 失效判断

push_back 未重新分配时，仅 end() 失效，元素引用与迭代器保持有效；重新分配则全部失效。`erase(begin(), begin()+1)` 使原 first（begin）及之后位置、以及 end() 失效，begin 之前（此处没有）不受影响。

## 7 两种二维表达

`vector<vector<int>>` 每行独立分配，`m[i][j]` 直观、适合整行处理，但两次间接访问且行间不连续；拍平 `vector<int>(r*c)` 连续存储、缓存友好，但下标要自己算 `i*c+j`。行数固定且注重局部性时选拍平，需要整行作为对象传递时选前者。关键不是“哪个更好”，而是能说明选择理由。
