# 第一课参考答案

先完成讲义练习，再阅读答案。

## 1 状态预测

[5,5] → reserve 后不变 → [5,5,7,7] → [5,5,7]。size=3，capacity 至少 10，不能要求恰好是 10。

## 2 下标错误

reserve 后 size 仍为 0。修复一是 a.push_back(8)；修复二是先 a.resize(1)，再 a[0]=8。两种都建立了实际元素。

## 3 长度翻倍

构造后已经有三个 0，追加后为 [0,0,0,1,2,3]。改成空容器后追加，或保留长度 3 并使用下标赋值。

## 4 分类

增加 std::vector<int> failed;，在原来的 if 后添加 else failed.push_back(x);。从左向右遍历并尾插，保持两组内部原顺序。不向正在遍历的 scores 追加。

## 5 删除末尾连续零

读入完成后：

```cpp
while (!a.empty() && a.back() == 0) {
    a.pop_back();
}
```

&& 从左到右短路，先判断非空才能访问 back。循环不变量：已删除部分仅为原序列末尾连续的零，保留部分仍是原序列前缀。终止时为空或末尾不是零，恰好完成任务。

测试：空→空；[0,0]→空；[1,0,0]→[1]；[0,1]→不变；[1,0,2,0]→[1,0,2]。最多删除 n 次，时间 O(n)，额外空间 O(1)。

## 6 失效和复杂度

reserve 参数超过当前 capacity 时重新分配，已有引用失效；未重新分配则保持有效。尾插均摊 O(1) 不排除单次扩容需要 O(n) 工作。
