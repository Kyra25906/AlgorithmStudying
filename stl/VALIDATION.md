# 第一课验证记录

验证日期：2026-10-05。环境：Windows，g++，C++17。

- 两个 examples 源文件以 -std=c++17 -Wall -Wextra -Wpedantic 编译成功，无编译告警。
- 状态程序完成全部断言：reserve 不增加元素、resize 新增 int 为零、clear 保留容量、副本与引用遍历不同、at 检查越界。
- 成绩程序核对了 5 组确切输出：讲义样例、n=0、单个 60、全部不合格、重复满分。

- capacity 增长序列仅作为当前实现观测，不要求固定倍数。

这些检查验证本课示例，不代表在线评测通过；练习题仍需学习者独立完成。运行入口见仓库 README。
