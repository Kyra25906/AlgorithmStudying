# 第13章 map 与 multimap

## 已知与所求

map 按键保持有序，单键唯一；multimap 允许等价键。`m[key]` 找不到时会插入默认值，读查询优先 `find` 或 `at`（不存在抛异常）。`try_emplace(k,v)` 仅在键缺失时构造映射值；`insert_or_assign(k,v)` 插入或覆盖。查找、插入通常 O(log n)。遍历修改 value 可行，不能就地修改 key。
