# 第十二章 set 与 multiset：动态有序集合

## 从静态排序走向动态查询

上一阶段可以先 sort，再二分查找。但若不断加入和删除数据，vector 中间修改需要移动后缀。有序关联容器把排序关系作为持续维护的约束：set 保存不重复的键，multiset 允许等价键重复。头文件均为 `<set>`。

标准保证相关查找、插入具有对数复杂度，常见实现是平衡搜索树；学习接口不需要依赖某一种树实现。容器没有下标访问，也没有第 K 小的直接接口。迭代器是双向迭代器，遍历按比较器顺序进行。

## 重复的定义来自比较器

默认 less<int> 下，set 插入 3、1、3 后遍历为 1、3，size 为 2。不是简单地额外调用 == 判断重复，而是 `!cmp(a,b) && !cmp(b,a)` 定义等价。

若记录比较器只比较成绩，则同成绩、不同姓名的记录在 set 中视为等价，只保留先插入的记录。想保留每个人，可以将姓名或唯一 id 纳入比较器，或者根据需求选择 multiset。比较器必须满足严格弱序，不能写 <=，也不能随着外部状态改变已有键的顺序。

## 插入、查询与返回值

| 操作 | set 返回值 | 复杂度与条件 |
|---|---|---|
| insert(x) | pair<iterator,bool> | O(log n)，bool 表示是否新插入 |
| find(x) | 指向等价键或 end | O(log n) |
| lower_bound(x) | 第一个不在 x 前面的键 | O(log n) |
| upper_bound(x) | 第一个严格在 x 后面的键 | O(log n) |
| equal_range(x) | 两个边界组成的 pair | O(log n) |
| erase(it) | 后继迭代器 | 摊还 O(1)，it 必须可解引用 |
| erase(x) | 删除数量 | O(log n + 删除数量) |

multiset.insert 返回迭代器，没有表示去重成功与否的 bool；count(x) 复杂度 O(log n + 匹配数量)，set 的 count 只有 0 或 1。

用成员 `s.lower_bound(x)`，不要用通用 `std::lower_bound(s.begin(),s.end(),x)` 代替：后者虽然比较次数是对数级，但沿双向迭代器步进可能需要 O(n)。对 multiset 的边界做 distance 统计数量也需线性走过匹配区间。

## 删除一个与删除全部

multiset 内容为 [2,2,2,5]，`erase(2)` 会删除全部三个 2，返回 3。只想删除一个，应先 find，确认不等于 end，再 `erase(it)`。不能直接 erase(end)。

遍历删除时采用 `it = s.erase(it)`，保留分支才 ++it。插入不使已有迭代器和引用失效；删除仅使被删元素的迭代器和引用失效。clear 则销毁全部元素。

set 的键不能通过迭代器修改，否则会破坏排序结构。C++17 的节点提取可支持先移出再改键，本课程在后续章节专门介绍。

## 边界问题：前驱与后继

默认升序下，lower_bound(x) 是第一个 >=x 的元素。若需要严格小于 x 的前驱，先取该边界；只有它不等于 begin 时才能 --。容器为空时 begin==end，仍会被这个条件挡住。找严格大于 x 的后继使用 upper_bound，并检查 end。

对 [1,3,3,7] 查询 3：lower 指向第一个 3，upper 指向 7，严格前驱是 1。查询 0 时没有前驱；查询 9 时没有后继。若使用降序比较器，“前后”依比较器定义，不能沿用数值大小的解释。

## 综合任务与验收

维护动态整数集合，支持加入、删除一个、询问某个值出现次数。没有重复时选 set；需要记录每次加入的数量时选 multiset。本课代码用 vector 作为独立参照，对一系列重复插入、单次删除、边界和计数进行核验。
