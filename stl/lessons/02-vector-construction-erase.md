# 第二课：修改 vector，并用它存一张表

第一课你已经会创建 vector、按下标访问，以及在末尾增删元素。这课解决三个具体需求：在中间插入一个数；删除所有符合条件的数；保存有行有列的矩阵。

建议分两次学习：先读第 1～7 节，完成删除练习；再学第 8 节的二维数组。整体复制、交换和移动放在第 9 节补充，失效规则放在第 10 节查阅。第一次不要求逐条背规则。

下面片段默认包含 `<vector>`，并使用 `using namespace std;`。使用输入输出还需 `<iostream>`。可运行文件见 [操作演示](../examples/02-vector-ops.cpp)、[安全删除](../examples/02-safe-erase.cpp)、[矩阵程序](../examples/02-matrix.cpp)。操作演示还包含补充知识，可以在读完主线后运行。

## 1 先明确：改值和增加元素是两件事

```cpp
vector<int> a = {10, 20, 30};
a[1] = 99;
```

结果是 `[10,99,30]`：20 被替换，仍有三个元素。

如果需求是保留 20，在它前面增加 99：

```text
[10,20,30] → [10,99,20,30]
```

元素数量变成四个，这需要 insert。反过来，移除一个元素并让后面的元素补位，需要 erase。

## 2 怎样表示位置？

下标 `a[1]` 取得元素，insert 和 erase 的位置参数则使用迭代器。这里先把迭代器理解为“标记数组中的一个位置”。

```cpp
a.begin()      // 第一个元素的位置
a.begin() + 1  // 下标 1 的位置
a.begin() + 2  // 下标 2 的位置
a.end()        // 最后一个元素之后的位置
```

```text
元素： [10][20][30] □
下标：   0   1   2
        ↑   ↑      ↑
      begin begin+1 end
```

end 不指向元素，不能解引用。空数组的 begin 和 end 相等。

```cpp
auto it = a.begin() + 1;
cout << *it; // 20
```

`auto` 让编译器推导类型；这里 it 是迭代器，`*it` 取得它指向的元素。

小检查：对于 `{10,20,30}`，`*(a.begin()+2)` 是 30。

## 3 insert：在指定位置前插入

```cpp
vector<int> a = {10, 20, 30};
auto it = a.insert(a.begin() + 1, 99);
```

逐步读：找到下标 1 的位置，也就是 20；在它前面插入 99。

```text
操作前：[10,20,30]
操作后：[10,99,20,30]
下标：   0  1  2  3
```

20 和 30 向后挪了一格。原下标 1 现在对应 99，所以不能总把下标当成某个元素的固定身份。

insert 返回指向新插入元素的迭代器，因此这里 `*it` 是 99。

```cpp
a.insert(a.begin(), 7); // [7,10,99,20,30]
a.insert(a.end(), 8);   // [7,10,99,20,30,8]
```

end 可以表示末尾插入位置，因为新元素就放在原最后一个元素后面。

小检查：对 `{1,2,3}` 执行 `insert(begin()+2,9)`，结果是 `{1,2,9,3}`。

## 4 erase：删除元素，让后面补位

```cpp
vector<int> a = {10, 20, 30, 40};
auto it = a.erase(a.begin() + 1);
```

```text
操作前：[10,20,30,40]
操作后：[10,30,40]
           ↑
        返回的 it
```

20 被删除；30 和 40 向前移动；erase 返回指向原被删元素后面那个元素的迭代器。因此 `*it` 是 30。

如果删除最后一个元素，返回新的 end，不能解引用。`erase(end())` 不合法，因为那里没有元素。

也可以删除范围：

```cpp
vector<int> b = {10, 20, 30, 40, 50};
b.erase(b.begin() + 1, b.begin() + 3);
// [10,40,50]
```

范围是左闭右开 `[first,last)`：包括下标 1，不包括下标 3，所以删除 20、30，保留 40。返回值指向原 last 位置的元素；删到末尾则返回新 end。

范围为空时不删除元素，例如 `erase(end(),end())` 合法。

## 5 边遍历边删除，为什么会漏掉元素？

需求：删除 `{3,3,1}` 中所有的 3。下面的循环会漏删：

```cpp
for (size_t i = 0; i < a.size(); ++i) {
    if (a[i] == 3)
        a.erase(a.begin() + i);
}
```

跟着执行：

```text
开始：      [3,3,1]，i=0
删除 a[0]： [3,1]，第二个 3 移到下标 0
执行 ++i：  i=1，检查的是 1
结束：      [3,1]，剩下的 3 没有检查
```

**当前位置补进了一个尚未检查的元素，此时需要继续检查当前位置。**

这段循环每次检查当前 size，具体错误是漏删；如果缓存旧长度作为边界，还可能越界。

## 6 删除后，旧迭代器为什么不能直接继续用？

迭代器关联着容器中的位置。删除让元素移动或销毁，删除点及其后的旧迭代器会失效。

```cpp
auto it = a.begin();
a.erase(it);
// 旧 it 已失效，不能继续 *it 或 ++it。
```

失效不会自动弹出提示，也不保证立刻崩溃。即使某次输出正常，也不能依赖它。

erase 已经提供了新的有效位置，所以这样接住它：

```cpp
it = a.erase(it);
```

右边先删除并返回下一处应该检查的位置；左边把新位置保存回 it。

先掌握这一条，就可以写删除程序。其他失效规则稍后查阅。

## 7 安全遍历删除

### 写法一：使用 erase 返回的新位置

```cpp
vector<int> a = {3, 3, 1};
int x = 3;

for (auto it = a.begin(); it != a.end(); ) {
    if (*it == x)
        it = a.erase(it);
    else
        ++it;
}
```

逐句解释：

- 从 begin 开始。
- 只要还没到 end，就有元素可检查。
- 当前元素要删除：接住 erase 返回的新位置，下一轮检查补进来的元素。
- 当前元素要保留：它已经检查完，用 ++it 前进。

for 的第三部分留空，因为是否前进由两个分支决定。

```text
[3,3,1] → [3,1] → [1] → 检查 1，前进到 end，结束
```

空数组不会进入循环。全部删光时，最后一次 erase 返回 end，也能正常结束。

### 写法二：把要保留的元素收集到新数组

```cpp
vector<int> kept;
kept.reserve(a.size()); // 预留空间，这行可以省略
for (int value : a) {
    if (value != x)
        kept.push_back(value);
}
a = kept;
```

对 `{3,1,2,3}` 删除 3：跳过 3，保留 1、2，再跳过 3，得到 `{1,2}`。最后用结果替换原数组。

遍历原数组，把结果写到另一个数组，原数组在遍历期间的位置不会改变，顺序也自然保留。

连续 erase 每次都可能移动后面的元素，最坏 O(n²)。筛选法连同最后的复制仍是 O(n) 时间，使用 O(n) 额外空间。删除很多元素时通常优先筛选法。

### 写法三：从后往前删除，作为补充

```cpp
for (size_t i = a.size(); i > 0; ) {
    --i;
    if (a[i] == x)
        a.erase(a.begin() + i);
}
```

删除后面的元素不会改变前面的下标。先判断 i>0 再递减，避免无符号 size_t 在 0 上减一回绕。最坏时间仍是 O(n²)。

现在动手：把条件改成 `<0`，删除所有负数。检查空数组、全负数、无负数、连续负数。

## 8 用 vector 存一张表

需求：保存两行三列。

```text
1 2 3
4 5 6
```

一行用一个 `vector<int>`；外层 vector 存这些行：

```cpp
vector<vector<int>> m = {
    {1, 2, 3},
    {4, 5, 6}
};
```

从内向外读类型：内层是一行，外层是多行。

```cpp
m[1]       // 第二行：[4,5,6]
m[1][2]    // 第二行第三个元素：6
m[1][2] = 9;
```

先选行，再选该行中的元素。行列下标都从 0 开始。

### 按输入的行列数创建矩阵

```cpp
int rows = 2, cols = 3;
vector<vector<int>> m(rows, vector<int>(cols, 0));
```

`vector<int>(cols,0)` 创建一行 cols 个 0；外层创建 rows 行的独立副本，修改一行不会同时修改其他行。

```cpp
for (int i = 0; i < rows; ++i) {
    for (int j = 0; j < cols; ++j)
        cin >> m[i][j];
}
```

外层选择行，内层从左到右填写这一行。

### 每行求和

```cpp
for (int i = 0; i < rows; ++i) {
    long long sum = 0;
    for (int j = 0; j < cols; ++j)
        sum += m[i][j];
    cout << sum << '\n';
}
```

sum 放在外层循环内，每换一行重新从 0 开始。long long 可容纳更大的和，题目范围仍需在它的上限之内。

### 转置：行列互换

```text
原矩阵：      转置后：
1 2 3         1 4
4 5 6         2 5
              3 6
```

原 `m[i][j]` 放到新 `t[j][i]`，新行数等于原列数：

```cpp
vector<vector<int>> t(cols, vector<int>(rows));
for (int i = 0; i < rows; ++i)
    for (int j = 0; j < cols; ++j)
        t[j][i] = m[i][j];
```

### 补充：拍平成一排

```text
1 2 3
4 5 6 → [1,2,3,4,5,6]
```

跳过前 i 行的 i*cols 个元素，再向右走 j 格：

```cpp
vector<int> flat(rows * cols);
flat[1 * cols + 2] = 6;
```

二维 vector 每行独立分配，行间不保证连续；拍平数组整体连续，要自己计算位置。两种按下标访问都是 O(1)，实际速度取决于使用方式。先用二维写法完成任务，再尝试拍平。创建大矩阵还需检查维度和乘积是否溢出。

## 9 补充：整体复制、替换、交换和移动

### 复制一份独立数据

```cpp
vector<int> a = {1, 2, 3};
vector<int> b = a; // 创建 b 并复制 a：拷贝构造
b[0] = 9;         // a=[1,2,3]，b=[9,2,3]
b = a;            // b 已存在，替换内容：拷贝赋值
```

拷贝构造处理 n 个元素，是 O(n)。赋值还需考虑目标原有元素的处理。

### assign 整体替换

```cpp
a.assign(3, 7);      // [7,7,7]
a.assign({1,2,3});   // [1,2,3]
vector<int> src = {9,8,7};
a.assign(src.begin(), src.begin()+2); // [9,8]
```

C++17 中不要用目标自身的迭代器区间作为 assign 来源，先建立临时副本。

### swap 交换所持内容

```cpp
vector<int> x = {1}, y = {2,3};
x.swap(y); // x=[2,3]，y=[1]
```

默认分配器场景无需逐个搬移元素，复杂度 O(1)。筛选法末尾的 `a=kept` 也可以改成 `a.swap(kept)`，交换后 kept 持有 a 原来的内容。

### 移动：熟悉复制后再读

```cpp
vector<int> a = {1,2,3};
vector<int> b = std::move(a); // 需要 <utility>
```

std::move 允许这里使用移动构造。普通 vector 移动构造可以接管存储，无需逐个复制，复杂度 O(1)。移动后的 a 有效，可以重新赋值、调用 size 或 empty，但不要预先假定内容或一定为空；访问 front、back 前仍须确认非空。

移动赋值需处理目标原有元素，不能一概说是 O(1)。自定义分配器还会影响移动和交换条件，本课练习使用默认分配器。

## 10 查阅：失效规则

失效有两个主要原因：整段存储重新分配，或元素移动、销毁。失效后不能继续用旧位置访问元素。

size 是实际元素数，capacity 是已分配空间能容纳的元素数。追加是否需要搬家，取决于剩余容量。

```cpp
vector<int> a = {10,20};
int& value = a[0];
a.push_back(30);
// 若重新分配，value 失效，不能继续访问。
```

仅尾部追加时可保存下标，操作后重新访问 a[index]；中间插入删除后，还要判断该下标是否对应原元素。

表中的元素相关位置包括引用、指针和迭代器。“全部失效”也包括旧 end。

| 操作 | 失效范围 |
|---|---|
| push_back / insert / emplace | 重新分配则全部失效；否则插入点及之后失效。尾部追加保留旧元素位置，但旧 end 失效 |
| erase(pos) | 删除点及之后，包括旧 end |
| erase(first,last) | 非空删除使 first 及之后失效，包括旧 end；空范围不改变容器 |
| pop_back | 被删元素相关位置及旧 end；其他元素仍有效 |
| resize 增大 | 重新分配则全部失效；否则旧元素有效、旧 end 失效 |
| resize 缩小 | 被删元素相关位置及旧 end 失效，保留元素有效 |
| resize 大小不变 | 无变化 |
| reserve(n) | n 超过当前 capacity 时重新分配，全部失效；否则无一失效。不改变 size |
| clear | 元素全部销毁，旧元素相关位置及旧 end 失效，capacity 不变 |
| shrink_to_fit | 可能不执行；重新分配则全部失效，否则不失效 |
| swap | 旧元素位置仍关联原元素，但归另一容器；重新获取 end |
| 拷贝赋值 / assign | 替换后重新获取所需位置，不沿用旧引用和迭代器 |

对本课 vector<int> 执行 `a[i]=100` 不改变大小，也不使容器迭代器失效。

范围 for 使用迭代器并保存结束位置，不要在遍历同一个 vector 时直接 push_back。只想检查原元素时，可先保存原长度，再用下标读取值；不要跨追加操作保存元素引用。

其他 insert 形式：`insert(pos,n,value)` 插 n 个值；`insert(pos,first,last)` 插区间副本；`insert(pos,{1,2})` 插列表。返回第一个新元素的位置，无插入时返回 pos。C++17 区间插入不能直接以目标自身迭代器为来源，先建临时副本。

中间插入删除通常 O(n)，push_back 均摊 O(1)，pop_back 为 O(1)。矩阵遍历与转置是 O(r·c)。

缩容补充：`vector<int>(a).swap(a)` 复制并交换，需 O(n) 时间和额外空间，不保证新 capacity 等于 size 或一定减小。释放给分配器不等于进程占用立刻下降。
