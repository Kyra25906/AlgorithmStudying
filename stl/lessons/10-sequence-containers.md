# 第十章 顺序容器与节点转移

## 先确定操作发生在哪里

已知要维护一个序列，先问：是否频繁按下标读取？是否两端插入？删除位置是否已经找到？在数组里中间删除要移动后缀；链表可以改连接，但从头找到第 k 项仍需走 k 步。

| 容器与头文件 | 存储与访问 | 常用修改 |
|---|---|---|
| array / `<array>` | 固定长度、连续、随机访问 O(1) | 不支持改变长度 |
| deque / `<deque>` | 非连续的随机访问 O(1) | 两端插删 O(1)，中间 O(n) |
| list / `<list>` | 双向迭代器，无下标 | 已知位置插删 O(1)，查找 O(n) |
| forward_list / `<forward_list>` | 单向迭代器，无下标、无 size | 已知前驱后插删 O(1) |

`std::array<int,3> a{};` 将三个整数初始化为零。array 的长度是类型的一部分；长度为零时 begin==end，不能调用 front/back。容器都管理自身元素生命周期，不需要手动 delete。

## deque：队列窗口的底层选择

push_front/push_back 插入，pop_front/pop_back 删除且不返回元素。取出前先检查 empty，再读取 front，最后 pop_front。两端插入会使迭代器失效，但已有元素的引用保持有效；不要把迭代器与引用规则混淆。中间插入会使迭代器与引用失效。两端删除仅使被删元素的引用失效；迭代器还需注意尾后位置，尤其删除最后元素时旧 end 不再有效。简单可靠的写法是修改后重新取 begin/end。

## list：把节点从一个序列接到另一个

`dst.splice(pos,src,it)` 把 src 中 it 指向的节点移到 dst 的 pos 之前，单节点转移 O(1)，不复制元素。it 必须可解引用；pos 必须属于 dst。两个容器的分配器必须相等。本课采用默认分配器的不同容器，避免自转移边界。

例如 src=[1,2,3]，dst=[9]，把 2 转移到 dst.begin()：src=[1,3]，dst=[2,9]。指向 2 的迭代器仍有效，但现在属于 dst。list 插入不使已有迭代器失效，删除只使被删节点的迭代器和引用失效。

整个 list 转移为常数复杂度；跨容器转移一个范围通常要线性计数，同容器范围转移为常数复杂度。节点插删的优势需要已知位置，否则仍要先付查找代价。

## forward_list：保存前驱

没有双向移动，所以接口是 insert_after 和 erase_after。before_begin 是首元素之前的特殊位置，不能解引用。删除当前元素时保留前驱：删除后前驱不动；保留当前元素时前驱前进。erase_after 返回被删节点之后的位置。

单节点 splice_after 转移的是给定迭代器后面的节点；范围版本使用开区间 (before_first,last)。不要照搬 list 的半开区间参数含义。

## 排序与选型

std::sort 要求随机访问迭代器，不能用于 list/forward_list；使用它们的成员 sort，复杂度 O(n log n)，且稳定。成员 remove_if 直接删除节点，不需要接 erase。list 的成员 unique 也会真正删除相邻等价节点。
