# 第16章 移动、emplace 与生命周期

## 已知与所求

移动允许转移对象所持资源；被移动对象仍有效，但其值通常不能再按原值假设。`emplace_back(args...)` 在容器末端直接构造，可能减少临时对象，但扩容仍可能移动既有元素。`string_view` 只借用字符，不拥有数据；不能返回指向局部 string 的 view。vector 扩容使原元素引用和迭代器失效。异常安全需结合具体操作和元素类型判断。
